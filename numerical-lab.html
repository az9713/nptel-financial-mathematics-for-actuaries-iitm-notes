Numerical laboratory

Each chapter contains a complete Python program and its exact printed output. Use these programs to test the equations against dates, units and boundary cases before trusting a numerical answer.

Run, predict, compare

Open a check below, copy its complete listing into a file, and run it with Python 3. The programs use only the standard library. Keep the original inputs for the first run and compare every output line with the chapter. Each check explains its assumptions, rounding and failure behaviour.

For a second run, change one stated input. Predict the direction of the change from the derivation before running the program, then explain any disagreement. Restore the original input before comparing with the printed output again. Read the chapter's boundary cases before substituting zero or negative rates.
